# Rushil Shah at Taasha Technologies — Software Developer (January 2020 to December 2020)

Taasha Technologies is where Rushil Shah started his professional software career, working there
through 2020 on an e-commerce platform. The work was full-stack with a database and search focus.

## Search over 20,000+ products

Rushil built the search box for an e-commerce website, giving users search and access across more
than 20,000 products held in a centralized inventory.

## Category-tree schema design — 30% latency improvement

To make the search filters fast, Rushil orchestrated the database design around a hierarchical
structure: products distributed across categories and sub-categories forming a tree. This made the
relational data less redundant and let the SQL queries behind the filters be much more efficient,
improving latency by about 30%.

This is the earliest example of a pattern that shows up throughout Rushil's career — reaching for
a data-modeling change rather than more hardware when something is slow.
