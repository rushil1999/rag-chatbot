# Rushil Shah's technical skills

## Languages

Rushil Shah's strongest languages are **Go (Golang)** and **Python**. Go is what he writes daily
at Tesla and wrote at Fetch Rewards — goroutines, the `context` package, concurrent workers, and
retry logic are all things he has used in production at scale. Python is what he builds AI and
data work in, including the FastAPI backend powering this chatbot.

He has also shipped production code in:

- **TypeScript and JavaScript** (Node.js, NestJS, React) — Procure Networks, Shipmnts
- **Java** (Spring Boot) — Taasha Technologies
- **Elixir** — InfluxData, where he learned it to build an AWS Marketplace simulator
- **Ruby** (Ruby on Rails) — Shipmnts, for the email notification system
- **SQL**, **C/C++**, HTML/CSS

## Backend and distributed systems

Microservices, REST, GraphQL, gRPC, event-driven architecture. Messaging and streaming with
**Kafka** and **RabbitMQ**, plus Redis-backed job queues and AWS SNS/SQS. Rushil has repeatedly
built cron- and poller-based scheduling systems, including adaptive polling that tunes its own
interval at runtime.

## Data stores and search

**MongoDB** (including Atlas Vector Search), **DynamoDB**, **PostgreSQL**, **Redis**,
**Elasticsearch** (inverted indexes, write-conflict handling), **Snowflake** data lake, and AWS
ElastiCache. Rushil has done schema design, denormalization for query performance, caching layers,
and a 314 GB production data migration.

## Cloud and infrastructure

**AWS** — Lambda, SES, SNS, SQS, ElastiCache, Elastic Beanstalk, Marketplace integrations.
**Docker**, CI/CD pipelines, **Grafana** for monitoring, Git.

## Frontend

**React** with TypeScript, custom hooks, Context API, Material UI, and Angular from his Taasha
Technologies work. He built and open-sourced a reusable React authentication component library.

## AI and machine learning

Retrieval-augmented generation (RAG), vector embeddings and vector search, LLM API integration,
SSE and HTTP token streaming, prompt design. Also convolutional neural networks (CNNs) and
traditional ML — classification and regression — from his master's coursework. Tools include
FastAPI, Cohere embeddings, MongoDB Atlas Vector Search, Grok (xAI) and Groq.

## Strengths

Rushil is at his best on backend performance and reliability problems: finding where a system is
wasting time or money and restructuring it. He is a fast learner of new stacks — picking up Elixir
for a single internship project is the clearest example — and works well in high-pressure, rapid
development environments. He values effective communication, team collaboration, and leadership.
